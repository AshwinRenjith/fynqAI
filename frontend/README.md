# fynqAI Liquid Glass Frontend

Apple-inspired glassmorphism interface for the fynqAI MVP. Built with Next.js 14, TypeScript, and Tailwind CSS.

## Getting Started

```bash
npm install
npm run dev
```

Visit `http://localhost:3000` to view the experience.

## Design Notes

- Liquid glass layers and blurred gradients mimic Apple visionOS/sonoma aesthetics.
- Components include window chrome, sidebar navigation, central copilot workspace, and right rail insights.
- All glass surfaces use shared utility classes for consistent lighting and depth.
